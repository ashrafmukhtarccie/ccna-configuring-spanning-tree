

# Configuring Spanning Tree

## Overview

This lab focuses on Spanning Tree Protocol (STP) and its role in preventing Layer 2 network loops.

## Objectives

* Understand STP operation
* Identify the root bridge
* Examine STP port roles
* Configure switch priority
* Verify STP operation

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Configured and verified STP to provide a loop-free Layer 2 topology.
